# Screenshots for kixlogic.com/hero

Drop PNGs in this folder using exactly these names. The page renders only the
ones that exist, so a missing file costs nothing and never shows a broken
image. Astro hashes and serves them; nothing else to wire up.

| file | what to capture |
|---|---|
| ribbon.png | The Kixlogic Hero ribbon tab, ideally with one menu open. |
| findings.png | Excel with the pane open, findings listed beside the sheet they came from. |
| disposition.png | A finding card with the Disposition dropdown in use. |
| split-by-manager.png | The manager tabs along the bottom, with one open. |

Before saving a shot, check it for anything you would not publish:

- The pane header shows the Install ID. Crop it out, or blur it.
- Use a benchmark or demo workbook, never a client's numbers.

Full-window captures at 100% zoom read best; the page scales them down.
Win + Shift + S crops to a selection; Win + PrtScn saves the whole screen to
Pictures\Screenshots.
